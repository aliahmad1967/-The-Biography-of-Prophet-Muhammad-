# الموسوعة التفاعلية للسيرة النبوية والتاريخ الإسلامي
### Interactive Seerah & Islamic History Encyclopedia

تطبيق تفاعلي شامل وموثق يعرض أحداث السيرة النبوية الشريفة وتاريخها المديد وفق منهج علمي رصين ومصادر إسلامية معتمدة.

---

## 🌟 أبرز المميزات (Key Features)

- **الخط الزمني التفاعلي (Interactive Timeline):** استعراض وتسلسل زمني لأهم أحداث السيرة الشريفة بدءاً من العصر الجاهلي والمولد الشريف، مروراً بالبعثة والهجرة الغراء والغزوات، وحتى رزيّة الخميس والوفاة الفاجعة.
- **مكتبة المعارف والمصادر الرقمية (Library & Sources):** توثيق شامل مع ربط مباشر بمجموعات **مكتبة المعارف الإسلامية - قسم السيرة والتاريخ** (مثل: *دروس في السيرة النبوية*، *شخصيات من السيرة*، *مفاهيم في السيرة النبوية*، *غزوات النبي ﷺ*، وغيرها).
- **أعلام وشخصيات السيرة (Character Profiles):** أشرعة تبيّن تراجم وحياة أهل البيت (عليهم السلام) والصحابة المنتجبين الذين رافقوا النبي ﷺ وضحوا في سبيل الدعوة.
- **المُساعد الذكي في السيرة (AI Assistant):** مساعد تفاعلي مدعوم بنموذج **Google Gemini** للإجابة عن الأسئلة والتحليلات التاريخية وفق المنهج الموثق.
- **الاختبارات التفاعلية (Interactive Quizzes):** تقييم وتثبيت المعارف حول الأحداث والشخصيات التاريخية بنظام نقاط ونسب إتقان.
- **عرض الخريطة والمواقع (Historical Map View):** استعراض المواقع والمشاهد التاريخية (مكة، المدينة، بدر، أحد، خيبر، حنين...) ببيانات جغرافية وتاريخية.
- **إدارة العلامات المرجعية (Bookmarks):** حفظ الأحداث والشخصيات المفضلة مع إمكانية الوصول السريع والتصفح في "وضع القراءة المخصص".
- **الوضع الليلي والنهاري (Dark & Light Mode):** دعم كامل للوضع الليلي والنهاري الواقي للعين مع خيارات اللغة العربية والإنكليزية.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend:** React 18, TypeScript, Tailwind CSS, Lucide / Material Symbols.
- **Backend:** Express.js (Node.js).
- **AI Integration:** `@google/genai` (Google Gemini API).
- **Build Tool:** Vite, esbuild, tsx.

## 🚀 التشغيل والتطوير (Getting Started)

### 1. تثبيت الاعتمادات (Install Dependencies)
```bash
npm install
```

### 2. إعداد متغيرات البيئة (Environment Variables)
قم بإنشاء ملف `.env` بناءً على `.env.example`:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```

### 3. تشغيل خادم التطوير (Development Server)
```bash
npm run dev
```
سيعمل التطبيق على المنفذ `http://localhost:3000`.

### 4. بناء المشروع للإنتاج (Production Build)
```bash
npm run build
npm start
```
